# Abhishek E-Commerce Portfolio Website

## Files
- index.html — main website
- style.css — responsive styling
- script.js — smooth navigation
- Abhishek_Ecommerce_Catalog_CV_Portfolio.pdf — CV + portfolio PDF

## Before publishing
1. Replace `91XXXXXXXXXX` in index.html with your WhatsApp number.
2. Replace `your.email@example.com` with your real professional email.
3. Replace the four sample-work placeholder boxes with your genuine screenshots.
4. Keep confidential seller data, private SKUs, phone numbers and dashboard information hidden.
5. Add your LinkedIn URL if you have one.

## Publish for free
### GitHub Pages
Create a GitHub repository, upload the files, then enable Pages from the repository settings.

### Netlify
Drag the entire folder into Netlify's deploy interface.

### Vercel
Import the project/repository and deploy as a static site.

No framework or build step is required.
